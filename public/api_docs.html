Automated Aadhaar Status Scraper API

Query real-time government enrolment and update statuses for SRN, URN, EID, and SID directly via REST API. Built on direct Tathya UIDAI endpoints with embedded neural network captcha solving.

Interactive Query Console

RESPONSE DURATION: 0ms 

      

    


    
    

      
      
      

        

          POST
          /api/v1/scrape
        

        

          Submit an identifier (or 14-digit EID with date and time) in a JSON payload and receive real-time UIDAI status with granular stages breakdown.
        


        

          

            
Option A: SRN or 28-Digit EID

            
{
  "identifier": "0867203160094120261014162256"
}

          

          

            
Option B: 14-Digit EID + Date & Time

            
{
  "eid": "0867/20316/00941",
  "date": "2026-10-14",
  "time": "16:22:56"
}

          

        


        

          
cURL Example (EID 14-Digit + Date/Time)

          
curl -X POST http://localhost:3000/api/v1/scrape \
  -H "Content-Type: application/json" \
  -d '{"eid":"08672031600941","date":"2026-10-14","time":"16:22:56"}'

        


        

          
Python (requests) Example

          
import requests

res = requests.post("http://localhost:3000/api/v1/scrape", json={
    "eid": "08672031600941",
    "date": "2026-10-14",
    "time": "16:22:56"
})
data = res.json()
print("Status:", data["status"])
print("Details:", data["status_details"])
print("JSON Data:", data["json_data"])

        

      


      
      

        

          GET
          /api/v1/scrape
        

        

          Direct URL query testing from browsers, cron webhooks, or simple HTTP scripts.
        


        

          
cURL Query String Examples

          
# 1. 28-digit EID direct:
curl -s "http://localhost:3000/api/v1/scrape?identifier=0867203160094120261014162256"

# 2. 14-digit EID with date and time:
curl -s "http://localhost:3000/api/v1/scrape?eid=08672031600941&date=2026-10-14&time=16:22:56"

# 3. SRN check:
curl -s "http://localhost:3000/api/v1/scrape?identifier=S1318711695580"
